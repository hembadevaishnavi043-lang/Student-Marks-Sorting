# Student-Marks-Sorting
Introduction

Student Marks Sorting is a simple application that arranges students' marks in ascending or descending order. The Divide and Conquer strategy divides the data into smaller parts, sorts them, and combines the results.

Problem Statement

To sort students' marks efficiently using the Merge Sort algorithm, which follows the Divide and Conquer strategy.

Objectives

- To understand the Divide and Conquer strategy.
- To sort student marks using Merge Sort.
- To display marks in sorted order.
- To understand the use of algorithms in real-life applications.

Technology Used

- Programming Language: Python
- Algorithm: Merge Sort
- Strategy: Divide and Conquer
